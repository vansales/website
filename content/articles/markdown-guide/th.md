ทุกวันนี้หลายๆ ระบบเลือกใช้ **Markdown** ในการเขียนเอกสาร — และ Vansales (ADP) ก็เป็นหนึ่งในนั้น เราใช้มันในหลายจุดทั่วทั้งระบบ ทั้งรายละเอียดสินค้า ข้อความและโน้ตต่างๆ เนื้อหาบทความอย่างหน้านี้ และช่องกรอกข้อความอื่นๆ แทนที่จะมีแถบเครื่องมือจัดรูปแบบ คุณแค่พิมพ์อักขระธรรมดาไม่กี่ตัว มันก็กลายเป็นหัวข้อ ตัวหนา รายการ และตาราง

เราจึงทำคู่มือสั้นๆ ที่เข้าใจง่ายชิ้นนี้ขึ้นมา เพื่ออธิบายว่ามันทำงานอย่างไร — ให้ทุกคนในทีมจัดรูปแบบข้อความได้อย่างมั่นใจ ไม่ว่าจะเจอ Markdown ตรงจุดไหนของระบบ

Markdown คือวิธีจัดรูปแบบข้อความง่ายๆ ด้วยอักขระธรรมดา คุณพิมพ์สัญลักษณ์ไม่กี่ตัว — `#`, `*`, `-` — แล้วมันก็กลายเป็นหัวข้อ ตัวหนา และรายการ นี่คือไวยากรณ์เดียวกับที่ใช้สร้างบทความชิ้นนี้ และเมื่อคุณรู้กฎเพียงไม่กี่ข้อ ก็เขียนเอกสารที่เป็นระเบียบได้ทุกที่ที่รองรับ Markdown

คู่มือนี้จะพาดูทุกองค์ประกอบที่คุณน่าจะได้ใช้ แต่ละอย่างจะมีทั้งโค้ดที่ต้องพิมพ์ และผลลัพธ์ที่ได้

## หัวข้อ (Headings)

ขึ้นต้นบรรทัดด้วยอักขระ `#` ตั้งแต่หนึ่งถึงหกตัว ยิ่งมี `#` มาก หัวข้อยิ่งเล็กลง

```
# หัวข้อระดับ 1
## หัวข้อระดับ 2
### หัวข้อระดับ 3
```

ใช้ `#` ตัวเดียวเป็นชื่อเรื่อง แล้วไล่ลงไปตามลำดับ — การข้ามระดับ (เช่นกระโดดจาก `##` ไป `####`) ทำให้เอกสารอ่านยากขึ้น

## การเน้นข้อความ (Emphasis)

ครอบข้อความด้วยสัญลักษณ์เพื่อจัดสไตล์:

- `*ตัวเอียง*` หรือ `_ตัวเอียง_` → *ตัวเอียง*
- `**ตัวหนา**` หรือ `__ตัวหนา__` → **ตัวหนา**
- `***หนาและเอียง***` → ***หนาและเอียง***
- `~~ขีดฆ่า~~` → ~~ขีดฆ่า~~

## รายการ (Lists)

รายการแบบจุด ให้ขึ้นต้นแต่ละบรรทัดด้วย `-`, `*`, หรือ `+`:

```
- รายการแรก
- รายการที่สอง
  - เว้นสองช่องเพื่อทำรายการย่อย
```

จะได้ผลลัพธ์เป็น:

- รายการแรก
- รายการที่สอง
  - เว้นสองช่องเพื่อทำรายการย่อย

รายการแบบตัวเลข ให้ใช้ `1.`, `2.` ไล่ไปเรื่อยๆ ตัวเลขจริงไม่จำเป็นต้องเรียงถูก — Markdown จะจัดลำดับให้เอง:

1. เตรียมเส้นทาง
2. โหลดสินค้าขึ้นรถ
3. เริ่มขาย

ทำเช็กลิสต์ได้ด้วย `- [ ]` และ `- [x]`:

- [x] ร่างบทความ
- [ ] ตรวจทาน
- [ ] เผยแพร่

## ลิงก์และรูปภาพ (Links & images)

ลิงก์เขียนเป็น `[ข้อความ](url)`:

```
[เยี่ยมชม Vansales](https://vansales.ai)
```

→ [เยี่ยมชม Vansales](https://vansales.ai)

รูปภาพเขียนแบบเดียวกัน แต่ใส่ `!` ไว้ข้างหน้า ข้อความในวงเล็บเหลี่ยมจะกลายเป็น alt text:

```
![หน่วยรถขายกำลังวิ่งเส้นทาง](/marketing/field-sales.jpg)
```

## ข้อความอ้างอิง (Blockquotes)

ขึ้นต้นบรรทัดด้วย `>` เพื่อยกคำพูด:

```
> ความต่างมักไม่ใช่ที่ตัวสินค้า แต่อยู่ที่การบริหาร
```

> ความต่างมักไม่ใช่ที่ตัวสินค้า แต่อยู่ที่การบริหาร

## โค้ด (Code)

ข้อความสั้นๆ ในประโยค ให้ครอบด้วย backtick เดี่ยว: `` `แบบนี้` `` → `แบบนี้`

โค้ดทั้งบล็อก ให้คร่อมด้วย backtick สามตัวบนบรรทัดของมันเอง:

````
```
const total = bills * profitPerBill;
```
````

จะได้ผลลัพธ์เป็น:

```
const total = bills * profitPerBill;
```

## ตาราง (Tables)

คั่นคอลัมน์ด้วยขีดตั้ง `|` และใช้ขีด `---` ใต้แถวหัวตาราง:

```
| ตัวชี้วัด        | เป้าหมาย |
| -------------- | ------- |
| สายต่อวัน       | 35      |
| % ที่ปิดการขายได้ | 60%     |
```

| ตัวชี้วัด        | เป้าหมาย |
| -------------- | ------- |
| สายต่อวัน       | 35      |
| % ที่ปิดการขายได้ | 60%     |

## เส้นคั่น (Horizontal rule)

ขีด `-` สามตัวขึ้นไปบนบรรทัดของมันเอง จะวาดเส้นคั่น:

```
---
```

---

## เคล็ดลับเล็กๆ น้อยๆ

- **บรรทัดว่างสำคัญ** เว้นบรรทัดว่างระหว่างย่อหน้า และก่อน-หลังรายการ หัวข้อ และบล็อกโค้ดเสมอ
- **เขียนให้เรียบง่าย** Markdown ออกแบบมาให้อ่านรู้เรื่องแม้ยังไม่ render — ถ้าข้อความดิบดูรก แสดงว่าคุณอาจจัดรูปแบบมากเกินไป
- **ไม่แน่ใจให้ดูตัวอย่าง** โปรแกรมส่วนใหญ่มีพรีวิวแบบสด ให้เช็กผลลัพธ์ได้ระหว่างพิมพ์

ทั้งหมดนี้ก็คือภาษา Markdown เกือบครบทั้งภาษาแล้ว จำรูปแบบสักสิบกว่าอย่างนี้ไว้ คุณก็จัดรูปแบบเอกสารได้แทบทุกชิ้นโดยไม่ต้องแตะแถบเครื่องมือเลย
